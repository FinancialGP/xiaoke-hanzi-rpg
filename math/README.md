# 森林数学大冒险 v1

给孩子玩的数学小游戏，纯静态网页，不用联网，不用注册，也不收集任何信息。

## 怎么打开
1. 解压 `kids-math-v1.zip`。
2. 双击 `index.html`，用 Chrome、Safari 或 Edge 打开。在平板上也可以用浏览器打开这个文件。
3. 点「➕ 新玩家」：孩子自己写名字，选一个动物头像，再选路线（学前档或小学档）。最多可以建 4 个玩家，每人的进度分开保存。
4. 进度存在**这台设备的这个浏览器**里（localStorage）。换设备，或者清除浏览器数据，进度就没有了。

## v1 内容
- **学前档（约 4 岁）**，共 4 站 12 关：
  - 🍄 数数（5 以内、10 以内、20 以内）
  - 🏞️ 认数字（听数字找数字；数字和物品数量配对）
  - 🌳 比多少（多、少、多一个、少一个）
  - 🌈 10 以内加减（看图、十格框、手指提示）
  - 题目会读出来，答案大多是点图案。
- **小学档（NZ Year 3）**，共 6 站 29 关，每站最后一关是有计时的「关底挑战」（多步应用题），按时完成可以得到奖杯：
  - 数位、数轴、单双数、找规律
  - 两位数和三位数加减（进位、退位）
  - 乘法表（2、5、10，3、4），除法（平均分、分组）
  - 认时间（整点、半点、一刻）和拨钟
  - 新西兰元：认钱币、算总数、凑钱、找零
  - 2D 和 3D 图形，数边、角、面
- 每轮 7 题。答错了可以再试：第一次答错出现提示图（十格框、方块、数轴、点阵），第二次答错，正确答案会发光。
- 自适应难度：连续 3 题又快又对，难度升一级；连续答错，难度降一级。
- 奖励：星星、💎宝石、30 张动物贴纸、6 个奖杯，都在「🎒 我的收藏」里。
- ⚙️ 家长设置：切换路线，选从哪一关开始，朗读语言（中文、English (NZ)、关闭），音效开关，清空进度，删除玩家。清空和删除都要点两次确认。
- 朗读用的是设备自带的语音。iPad 或 Mac 上如果没有声音，请检查静音键，或者在系统设置里下载中文或英文语音。

所有画面都是原创的 emoji、SVG 和 CSS。钱币是简化画法，不是真币图案。
